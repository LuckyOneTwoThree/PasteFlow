## 1. 设计哲学与全局视觉 Token 规范 (Design System & Tokens)

### 1.1 核心交互设计铁律

1. **零焦点打断（Zero Focus Stealing）**：所有浮层（胶囊 Toast、光标微胶囊 `Micro-HUD`、贪吃蛇角标）弹出与交互期间，宿主应用（Word、微信、VSCode）的光标保持闪烁，绝不触发窗口失焦变灰。
2. **克制而确定的微反馈（Calm & Deterministic Feedback）**：自动挡接管提示仅在 `260ms` 消抖后轻量浮现 `800ms` 即自动消失，不设关闭按钮、不遮挡正文字体。
3. **分阶段界面演进**：
   * **v0.1.0（极简菜单栏引爆版）**：仅包含「原生系统菜单栏控制中心」+「原生无焦点胶囊 Toast」，零常驻 Webview，极致轻量。
   * **v0.1.5（完整交互版）**：挂载常驻隐藏的 `Micro-HUD`（宽 `260px`）、磁吸式侧边抽屉（宽 `360px`）与按需创建的滤镜商店主面板（`880px × 600px`）。

### 1.2 明暗双色设计 Token (Color & Material Tokens)

所有浮层均采用系统级毛玻璃材质（macOS `NSVisualEffectView` `material = .hudWindow` / `.menu`；Webview 层配合 `backdrop-filter: blur(20px) saturate(180%)`）：

| Token 名称 | Light Mode（浅色模式） | Dark Mode（深色模式） | 用途说明 |
|---|---|---|---|
| `--pf-surface-hud` | `rgba(255, 255, 255, 0.84)` | `rgba(28, 28, 32, 0.86)` | `Micro-HUD` 与胶囊 Toast 主背景 |
| `--pf-surface-drawer` | `rgba(248, 249, 251, 0.90)` | `rgba(22, 22, 26, 0.92)` | 侧边历史与贪吃蛇抽屉背景 |
| `--pf-border-subtle` | `rgba(0, 0, 0, 0.08)` | `rgba(255, 255, 255, 0.12)` | 1px 内发光描边，确保在同色壁纸上的边界清晰度 |
| `--pf-text-primary` | `#111827` | `#F9FAFB` | 主标题、菜单项主文案 |
| `--pf-text-secondary` | `#4B5563` | `#9CA3AF` | 副标题、应用来源说明、快捷键提示符 |
| `--pf-accent-brand` | `#4F46E5` (Indigo 600) | `#6366F1` (Indigo 500) | 品牌主色、自动挡激活态、键盘导航选中高亮 |

| `--pf-accent-dlp` | `#DC2626` (Red 600) | `#EF4444` (Red 500) | DLP 敏感凭证保护提示徽章 |

### 1.3 字体排印与动效规范 (Typography & Motion)

* **字体栈**：
  * UI 界面字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`
  * 代码与快捷键徽标：`"SF Mono", "JetBrains Mono", Menlo, Consolas, monospace`
* **动效曲线（Framer Motion / CoreAnimation）**：
  * `Micro-HUD` 弹出：`type: "spring", stiffness: 520, damping: 32, mass: 0.6`（缩放 `0.94 → 1.0`，透明度 `0 → 1`，总耗时 `< 120ms`）。
  * 胶囊 Toast 进出场：入场 `120ms ease-out`（上移 `4px`），停留 `800ms`，出场 `180ms ease-in`（透明度 `1 → 0`）。

## 2. v0.1.0 极简菜单栏引爆版界面规范 (Phase 1A UI Spec)

### 2.1 菜单栏状态图标 (Menu Bar Status Icon)

常驻于 macOS 顶部菜单栏右侧（`22px × 22px` 单色 Template Image，自适应系统明暗状态栏）：

| 状态 | 视觉表现 | 触发条件 |
|---|---|---|
| **静默守候态（Idle）** | 简洁剪贴板流线图标（无角标） | 自动挡开启，当前剪贴板未被接管或已失去所有权 |
| **持有就绪态（Owned Active）** | 剪贴板图标右上角带微型星芒点 `✨` | 当前剪贴板已被 PasteFlow 接管，等待目标应用按下 `⌘V` |
| **贪吃蛇收集态（Stacking, v0.1.5）** | 图标旁紧跟胶囊数字 `🐍 5` | 开启连续收集槽时实时显示已收集片段数 |
| **暂停态（Paused）** | 图标半透明（`opacity: 0.45`）并带斜杠 | 用户临时关闭自动挡 |

### 2.3 260ms 消抖无焦点胶囊 Toast (Debounced Capsule Toast)

* **尺寸与层级**：高度固定 `32px`，水平内边距 `12px`，圆角 `9999px`（全胶囊形），窗口层级 `NSPopUpMenuWindowLevel`，属性 `ignoresMouseEvents = true`（鼠标点击直接穿透至底层窗口，绝不拦截鼠标操作）。
* **定位与屏幕边缘防裁切规则**：
  * 默认锚点：当前鼠标指针屏幕坐标 `(mouse.x + 12px, mouse.y - 40px)`（即鼠标右下角）。
  * 边缘翻转：若 `mouse.x + toast.width + 20px > screen.visibleFrame.maxX`，则向左翻转对齐至 `mouse.x - toast.width - 12px`；若下方空间不足则向上翻转至 `mouse.y + 20px`。
* **四种标准状态文案**：
  1. **Markdown 智能接管态**：`✨ 灵贴就绪 · Word 贴排版 · 微信去星号 · 终端保源码`（右侧带浅色提示标签 `双击 ⌘C 还原`）
  2. **社媒链接净化态**：`🔗 已剥离 3 个追踪参数与口令尾巴`（右侧带标签 `双击 ⌘C 还原`）
  3. **双击 `⌘C⌘C` 还原确认态（v0.1.0）**：`↩️ 已还原为原始未转换文本`
  4. **显式脱敏确认态**：`🛡️ 已将 2 处敏感密钥替换为 <REDACTED>`

### 2.4 macOS 15.4+ 剪贴板访问权限轻量引导卡

当启动时检测到 `NSPasteboard.general.accessBehavior != .alwaysAllow`（例如处于 `.ask` 状态）时，在菜单栏图标下方弹出一次性非模态引导气泡（宽 `320px`）：

* **标题**：`开启零打扰智能粘贴体验`
* **正文**：`为避免 macOS 在每次复制时弹出粘贴确认框，请在系统设置中将「灵贴 PasteFlow」的「从其他 App 粘贴」设为【始终允许】。`
* **主按钮**：`打开系统隐私设置`（点击直接通过 URL Scheme `x-apple.systempreferences:com.apple.preference.security?Privacy_Pasteboard` 跳转对应面板）+ 次按钮 `稍后提醒`。

## 3. v0.1.5 光标微胶囊手动挡规范 (`Micro-HUD`, Phase 1B)

### 3.1 像素级容器布局规范

```text
┌────────────────────────────────────────────────────┐  <-- 宽 260px, 圆角 14px, 内边距 8px
│ 📄 来自 Chrome · Markdown (2.4 KB)          [ESC]  │  <-- 顶部上下文状态栏 (高 24px, 11px 字体)
├────────────────────────────────────────────────────┤
│ ▶ 1  ✨ 转为微信精致纯文本                    [↩]  │  <-- 选中态: 背景 --pf-accent-brand, 白色文字 (高 32px)
│   2  📊 转为 Word / 飞书原生富文本                 │  <-- 默认态: 高 32px, 圆角 8px, 左右内边距 10px
│   3  🛡️ 脱敏隐藏密钥 (<REDACTED>)                  │
│   4  💼 AI 职场高情商润色 (L3)                     │
├────────────────────────────────────────────────────┤
│   0  ↩️ 粘贴原始未转换内容                         │  <-- 底部保底项 (高 30px)
└────────────────────────────────────────────────────┘
```

* **尺寸约束**：固定宽度 `260px`；单行动作项高度 `32px`，行间距 `2px`；折叠态总高度不超过 `210px`。
* **坐标定位三级回退**：
  1. **Tier 1（已授 Accessibility）**：调用 `AXUIElement` 获取文本光标 `caret_rect`，弹窗左上角对齐 `(caret_rect.x, caret_rect.maxY + 6px)`。
  2. **Tier 0（默认零权限）**：对齐当前鼠标指针 `(mouse.x + 12px, mouse.y + 12px)`。
  3. **越界回退**：若鼠标在活动窗口屏幕外，居中显示于当前活动窗口底部向上 `120px` 处。

### 3.2 键盘与鼠标无焦点交互状态机

* **按键映射**：
  * 数字键 `1`–`4`：直接触发对应编号滤镜并立即执行上屏；
  * 数字键 `0` 或 `Backspace`：触发「粘贴原始未转换内容」；
  * 方向键 `↑` / `↓` 或 `Tab`：循环移动高亮选中行（默认高亮第 `1` 项）；
  * `Enter` (`↩`)：执行当前高亮行动作；
  * `Esc` 或点击胶囊外部任意区域：立即隐藏 `Micro-HUD`，保持自动挡接管状态不变。
* **Tier 0 与 Tier 1 上屏反馈差异**：
  * **Tier 1（自动注入）**：按下 `1`–`4` 后，`Micro-HUD` 在 `80ms` 内缩小淡出，后端写入剪贴板并自动发送 `⌘V` 完成上屏。
  * **Tier 0（零权限写回）**：按下 `1`–`4` 后，`Micro-HUD` 原地变形为单行绿色确认胶囊 `✅ 已准备就绪，请按 ⌘V 粘贴`，停留 `600ms` 后自动淡出。

### 3.3 L3 AI 流式预览展开态规范

当用户在 `Micro-HUD` 中选择 L3 动作（如 `4 AI 职场高情商润色`）时，微胶囊宽度平滑扩展至 `340px`，高度动态展开至 `220px`：

1. **生成中状态（Streaming）**：
   * 顶部显示呼吸灯动画 `⚡ AI 正在润色... (首字 320ms)`；
   * 中部为最大高度 `140px` 的自动滚动预览框，实时流式渲染生成的文本；
   * 底部操作栏：`[Esc 取消]`。
2. **生成完成状态（Ready to Paste）**：
   * 预览框展示完整结果，底部操作栏高亮 `[↩ 确认粘贴]` 与 `[⌘C 仅复制]`；
   * 用户按 `Enter`（或若开启“L3 完成后自动原子粘贴”），将完整生成结果一次性写入剪贴板并执行单次原子粘贴，彻底杜绝逐字按键注入导致的跨窗口误喷与撤销栈碎裂。

## 4. v0.1.5 磁吸式历史与贪吃蛇侧边抽屉规范 (`History & Stack Drawer`)

### 4.1 抽屉容器与唤醒机制

* **尺寸与停靠**：宽 `360px`，高为当前屏幕可用高度 `screen.visibleFrame.height - 24px`（上下各留 `12px` 悬浮边距），默认停靠于屏幕右侧边缘，圆角 `16px`。
* **唤醒与收起**：按 `⌥⇧V`（macOS）/ `Alt+Shift+V`（Windows）切换显示/隐藏；按 `Esc` 或点击抽屉外区域自动滑出屏幕右侧隐藏。

### 4.2 顶部搜索栏与贪吃蛇收集槽控制区

* **搜索框**：支持中英文 FTS5 毫秒级实时过滤，配备类型胶囊过滤标签：`全部` | `✨ Markdown` | `🔗 链接` | `💻 代码` | `🖼️ 图片`。
* **🐍 贪吃蛇连续收集槽面板（开启 `⌥⇧S` 时在抽屉顶部展开）**：
  * 显示当前队列条目列表 `StackQueue[1..N]`（支持拖拽排序与单条移除）；
  * 底部三大一键消费按钮：
    * `[换行合并粘贴]`（主按钮，快捷键 `⌘↩`）
    * `[去重编号列表]`
    * `[✨ AI 智能汇总]`（下拉可选：`生成会议纪要` / `生成对比表格` / `提取待办清单`）

### 4.3 历史条目卡片交互

每张卡片高 `84px`，展示：
* 左上角：复制源应用图标 + 应用名（如 `🌐 Google Chrome`）+ 相对时间（`2 分钟前`）；
* 右上角：内容特征徽章（如 `Markdown`、`已瘦身链接`）+ 置顶图钉图标 `📌`；
* 正文区：最多展示 2 行摘要；鼠标悬停时显示 `[预览转换效果]` 切换按钮，点击可在卡片内就地切换查看 `原始文本 (Before)` 与 `富文本渲染效果 (After)`。

## 5. v0.1.5 滤镜商店主面板与诊断看板规范 (`Main Dashboard`)

主面板尺寸 `880px × 600px`，采用左侧导航栏（`200px`）+ 右侧内容区（`680px`）布局，按需创建并在关闭窗口 `30s` 后自动销毁 Webview 释放内存：

1. **Tab 1 — 魔法滤镜商店（Magic Filters）**：
   * 顶部角色预设快捷栏：`💼 日常办公` | `📊 财务数据` | `🎓 学术研究` | `💻 开发者`。
   * 双列网格展示所有内置与自定义 `PipeRecipe` 卡片：包含开关状态（`自动挡 Auto` / `仅手动 Manual` / `关闭 Off`）、转换前后对比演示框、纯文本通道策略下拉框（`智能按目标应用 DYNAMIC` / `保持源码 PASSTHROUGH` / `始终净化 CLEANED`）。
2. **Tab 2 — 本地可观测性与诊断看板（Diagnostics & Metrics）**：
   * 实时展示当前剪贴板 `changeCount`、最近 20 次粘贴回调的 `FrontmostApp` 识别日志与耗时（精确到微秒 `µs`）、`FormatGate` G1–G5 护栏拦截统计饼图，以及 `[一键导出脱敏诊断包]` 按钮。
3. **Tab 3 — AI 与权限设置（Settings）**：
   * Tier 1 辅助功能（Accessibility）权限显式开关与风险说明；
   * L3 模型配置（OpenAI 兼容 Base URL、API Key、模型名称与本地 Ollama 一键探测连接测试）。
